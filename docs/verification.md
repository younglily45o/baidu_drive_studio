## 测试覆盖

本地 TCP HTTP 服务实际接收 reqwest 请求，验证中文路径编码、分页偏移、OAuth HTTP 400 pending、错误描述不回显令牌、Refresh Token 轮换及共享会话。慢速刷新测试验证凭据快照不等待网络锁。

下载测试检查完整文件发布、不覆盖已有或并发创建的用户文件、连接截断后续传、Range 起点异常拒绝、服务器返回 200 时从头下载、身份改变拒绝旧断点、取消保留完整临时文件后恢复。Windows 使用不带覆盖标志的 `MoveFileExW`；Linux 使用 `RENAME_NOREPLACE`。

上传测试验证服务端只要求部分分片时按索引上传、合并仍提交完整有序哈希、非法分片索引拒绝、取消后不发出合并请求。

egui 无窗口测试绘制登录前的三个页面和已登录文件/失败传输页面，检查取消队列、退出登录丢弃旧授权消息、接收完成状态及可选容量查询不阻塞列表。文件夹选择回归会向 egui 注入鼠标移动、按下和释放事件；未启动真实 Windows 窗口。

## Cookie 与直链增量验证

Cookie 解析覆盖完整请求头值、重复键、引号值和等号、非法控制字符及 BDUSS 缺失。0.2.1 使用虚构凭据复现单独 `undefined;` 导致的拒绝，验证只忽略该残留项、保留 `undefined=值`，其它非法项和头注入仍拒绝。实际 HTTP 测试覆盖会话验证、分页、CSRF、签名与所选 ID、元数据到文件下载发布、Cookie 上传完整/分片哈希和 CRC32。OAuth 旧凭据兼容测试通过。

直链测试区分无 Cookie 通过、需要会话、403/登录页、异常 Range 和长度、跨域重定向拒绝、Cookie 的主机范围。页面先有无关 timestamp 的签名回归通过。上传 precreate/create 均改为 rtype=1，测试防止再次使用覆盖参数 3。

实际无 Cookie 请求 `/api/gettemplatevariable` 和 `/api/download` 均得到 HTTP 200、errno=-6：接口可达且要求登录。详见 [direct-link-feasibility.md](direct-link-feasibility.md)，这不证明真实账号直链可用。

## 0.3.0 文件夹下载与左对齐

本地 HTTP 测试覆盖 Cookie 与 OAuth 分页、子目录递归、空目录、选中父子项去重、失败/取消时不返回部分计划、重复 ID、路径越界、不安全 Windows 名称和大小写冲突。目录准备不会覆盖已有文件，拒绝子目录符号链接。完整链路测试从目录扫描、网页元数据查询到内容下载，在嵌套目录实际生成 `a.txt` 并核对字节内容，确认临时文件已清理、空目录仍存在。

界面测试从绘制形状定位文件夹复选框，注入鼠标点击，确认能够选中且不触发目录导航。测试扫描完成加入嵌套目标、扫描失败不入队、取消后丢弃晚到结果、扫描时阻止注销，以及直链验证仅允许单个普通文件。批次目标一次建集合后追加，活动目标不重复；1,001 项队列的绘制测试验证只显示所选页，完整队列不被分页删除。

名称绘制测试在 960、1180、1600 点窗口宽度下读取实际文本位置，确认文件名、文件夹名与“文件名”标题的左边缘对齐，并且处于窗口左侧。

Windows 最终发布使用规范化后的扩展长度路径，仍禁止覆盖。新增超过 260 字符路径的下载发布及已有文件不覆盖测试，仅在 Windows 目标下编译，当前 Linux 主机未运行此项。目录创建不是原子事务，准备阶段失败或取消可能保留已创建的空目录。
